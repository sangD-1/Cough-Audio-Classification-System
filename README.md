# Cough-Audio-Classification-System

The proposed project is titled AI-based Cough Audio Classification System that classifies cough sounds based on the given audio clips through conventional machine learning as well as deep learning methods. The MFCC-Based Feature Extraction with SVM method and Spectrogram-Based Classification with CNN approach was applied for feature extraction and classification of the audio dataset respectively.
Different techniques for processing the audio dataset, such as noise reduction, feature extraction, and spectrogram creation were used to enhance model efficiency. The project was executed in Python and machine learning algorithms.
In this project, audio signal processing and machine learning methods have been applied in sound classification problems related to healthcare applications.
